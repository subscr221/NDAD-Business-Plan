## GLOBAL STYLE (prepend or keep consistent across all 10)

**Style bible:** Flat 2D vector motion-graphic frame, clean corporate-cinematic infographic aesthetic, premium defense-tech brand film. Deep navy background (#0A1A2F), signal-blue primary (#1E6FE0 / #4DA3FF), single warm amber accent (#FFB020) used sparingly for emphasis. Subtle grid + thin circuit/topographic linework, soft volumetric glow, faint film grain, crisp geometric shapes, generous negative space, no photorealism. Thin 1–2px strokes, rounded corners, restrained gradients. Cohesive icon set, minimal. Cinematic key light from upper left. 16:9, 4K, high detail, poster-clean composition.

**Aspect ratio:** 16:9 (3840×2160). **Text:** leave clean empty zones for captions to be added in post — do not bake in paragraphs of text; short labels only if the tool renders type reliably, otherwise render text-free.

**Global negative prompt:** photorealistic photo, real human faces, logos of real companies, watermark, signature, jpeg artifacts, cluttered, busy, neon rave colors, cartoon mascot, childish, low-res, blurry, distorted geometry, gore, realistic weapons close-ups, misspelled text, gibberish text, stock-photo look.

## PRODUCTION NOTES

- **Consistency trick:** generate Scene 3 and Scene 10 first — the hexagonal platform core is your recurring motif. Lock its shape/color, then reference it in prompts for Scenes 4, 5 and 10 ("the same luminous hexagonal core as established").
- **Seeds:** once you get a frame you love, reuse its seed across scenes for a coherent look.
- **Text-safe:** keep AI-rendered type to short labels only; add all precise figures (₹105 Cr, 31.9% IRR, etc.) as clean vector text in After Effects/your editor — image models misspell numbers.
- **Deliverable set per scene:** a clean "empty" plate (no text) + a version with placeholder label zones, both 3840×2160.
- **Palette hex:** navy #0A1A2F · blue #1E6FE0 / #4DA3FF · amber #FFB020. Feed these into any tool that accepts color guidance.
